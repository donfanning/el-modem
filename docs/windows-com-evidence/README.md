# windows-com-evidence

Captured machine output from the `v0.1.0-rc1` Windows COM qualification run
(Tera Term 5.7.1 through com0com 3.0.0.0 and com2tcp 1.3.0.0 on Windows Server
2022). See [../WINDOWS_COM_QUALIFICATION.md](../WINDOWS_COM_QUALIFICATION.md)
for the write-up.

**These files are evidence and are deliberately not edited.** They record what
a real machine actually reported, including the COM41/COM42 pair that run
created. Normalising the values would make the evidence disagree with the run it
documents.

This arrangement is superseded by the bundled virtual-COM driver; see
[../WINDOWS_DRIVER.md](../WINDOWS_DRIVER.md).
