# Contributions

The community edition uses GPL-3.0-or-later. Separate commercial licensing is
part of the project model. Before accepting outside code, the project needs a
contributor agreement granting sufficient rights for both community and
commercial licensing. That agreement is not finalized yet.

For now, please submit bug reports, reproducible failures and feature requests.
Outside code contributions are not being accepted until that agreement is
available. A normal GPL submission or a Developer Certificate of Origin alone
does not supply the necessary proprietary relicensing rights.

Do not post service credentials, phone/account identifiers, private call logs,
or third-party recordings without redistribution permission. For a modem issue,
describe the OS, build revision, serial backend, engine/profile, transport,
expected behavior and a local reproduction where possible. Remove credentials
before attaching configuration or diagnostics.
